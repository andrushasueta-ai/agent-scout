# Agent Scout

## Стек
- Python 3.11+, async/await
- Playwright + playwright-stealth
- SQLAlchemy 2.0 (async) + SQLite
- Pydantic v2 для валидации
- Click для CLI
- anthropic SDK для Claude API

## Конвенции
- Весь код в src/agent_scout/
- Каждый модуль — один файл, одна ответственность
- Типизация: все функции с type hints
- Docstrings на русском
- Async по умолчанию для I/O операций
- Логирование через structlog, не print()

## Слои (не смешивать!)
- browser/ — только управление браузером и anti-detection
- platforms/ — только парсинг конкретных площадок
- database/ — только хранение и CRUD
- messenger/ — только AI-переписка
- orchestrator.py — только координация

## Контекст продукта
- Используется ОДИН реальный аккаунт пользователя на каждой площадке
- Агент логинится под этим аккаунтом, НЕ создаёт новые
- Cookies сессии сохраняются между запусками (data/sessions/)
- Прокси — опционально, для защиты IP, НЕ для мульти-аккаунтов
- Цель: собрать максимум контактов за несколько дней

## Модель поведения "живого пользователя"
- Рабочие часы: 9:00-22:00 МСК (не раньше, не позже)
- Сессия: 15-40 мин активности -> 20-90 мин перерыв
- Сообщений в день: 8-15 первых обращений (не 50)
- Ответы на входящие: задержка 3-20 мин (не мгновенно)
- Паттерн дня: утром больше просмотров, днём переписка, вечером меньше
- Выходные: активность снижена на 30-50%

## Правила
- Не трогать файлы за пределами текущей задачи
- Каждый новый модуль — сначала план, потом код
- Тесты пишутся сразу после модуля
- Импорты только из своего слоя или из слоя ниже
